# Server parameters: what is fixed and what is not

## Fixed in the code (changed only by recompiling)
| value | where | value |
|---|---|---|
| minimum root | `session.rs` `ROOT_MIN` | 2048 tokens |
| sampling defaults | `crates/api/src/lib.rs` `Params::default` | temperature 0.6 · top_p 0.95 · top_k 20 · seed 0 |
| max generated tokens (default) | `crates/api/src/lib.rs` | 8192 |
| maximum top_k | `session.rs` | 1000 |
| SSE keep-alive | `crates/server/src/lib.rs` `KEEPALIVE` | every 10 s |
| prefill block sizes and their costs | `engine.rs` `BLOCKS`, `COST` | 512/128/32/8 |
| maximum request body | `crates/server/src/http.rs` | 64 MB |
| chat template | `crates/chat/template.jinja` | the official Qwen one |

## Set at startup (environment variables)
| variable | effect | default |
|---|---|---|
| `MECHTA_MODEL` | model file (GGUF) | required |
| `MECHTA_TOKENIZER` | tokenizer.json of the model (`tokenizers/` at the repository root) | required |
| `MECHTA_CACHE` | roots folder | required |
| `MECHTA_CTX` / `serve --ctx N` | maximum context (`engine::ctx()`; 4096-262144, multiple of 1024) | 65536 |
| `MECHTA_ADDRESS` | listen address | `127.0.0.1:4131` |
| `MECHTA_THINKING=no` | thinking off by default | on |
| `MECHTA_ROOT=no` | no root shared between sessions | on |
| `MECHTA_MTP=no` | no MTP | on |
| `MECHTA_MTP_TAIL` | tail tokens at single step | 8 |
| `MECHTA_TITLES=engine` | titles generated by the model | first words of the question |
| `MECHTA_KEEPALIVE=no` | no SSE comments | on |
| `MECHTA_SAVE_REQUESTS` | folder where requests are saved | off |
| `MECHTA_RESERVE_GB` | VRAM kept free while the weights load | 0 (`mechta-serve.sh` sets 2) |

The full list is in `USAGE.md`. The other `MECHTA_*` variables (`ATTN`, `GEMM_*`, `DELTA`, `ORDER`, `FAKE_POS`,
`REJECT`...) select kernel variants: measurement only.

## Set per request (from the client, OpenAI fields)
`temperature`, `top_p`, `top_k`, `seed`, `max_tokens` / `max_completion_tokens`,
`chat_template_kwargs.enable_thinking`. The fixed default applies only if the client does not send them.

## Duplicates to keep aligned
`engine/opencode-mechta.json` repeats by hand the context (131072) and the output limit (32768).
